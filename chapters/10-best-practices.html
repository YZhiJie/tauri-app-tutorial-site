第 10 章 · 最佳实践与进阶方向 ​

小塔：「恭喜走到这里！最后一章不教 API，我们把前九章的经验沉淀成清单和地图，然后……旅程才刚刚开始。」

本章学习目标 ​

  • 沉淀架构 / 安全 / 性能 / 工程化四张实践清单
  • 明确技术选型的判断标准（而不是背答案）
  • 拿到结业后的进阶功能地图与学习资源

10.1 架构最佳实践 ​

命令分层：commands 要薄，服务要厚 ​

text
commands/   只做：参数接收 -> 调用 service -> 序列化结果/错误
services/   业务规则、状态、持久化（本教程的 NotesStore / NotesStorage）

命令层不要堆业务逻辑——否则同一规则被多个入口（命令/事件/导入）复制后必然漂移。 本教程第 8 章的导入功能复用 store.insert 就是这条原则的示范。

状态管理 ​

  • Rust 端共享状态走 Mutex/RwLock，锁粒度要小、不要嵌套加锁（本应用三把独立锁）；
  • 写流程保持「先持久化成功，再改内存」，崩溃后内存可从磁盘重建；
  • 前端单一数据源（composable），组件不直接持有业务状态；
  • 跨语言边界只传 DTO（serde 结构），不传 Rust 引用或前端对象。

错误处理选型 ​

工具适用
Result<T, String>命令边界：错误要直接展示给用户（教学阶段最清晰）
thiserror库/服务层：定义领域错误枚举，#[from] 自动转换
anyhow应用内部、一次性脚本：不关心错误类型时

正式项目推荐：服务层 thiserror 枚举 → 命令边界统一转成用户可读消息/错误码。

10.2 安全清单 ​

发布前逐项过：

  • [ ] 权限最小化：capability 里每个权限都能说出用途；不用 * 通配；
  • [ ] CSP：无远程域名通配，禁内联脚本；新增外部依赖时按指令精确放开；
  • [ ] 路径穿越：用户输入进入路径前过滤/规范化（storage 的 [a-zA-Z0-9-] 白名单）；
  • [ ] 命令注入：非必要不碰 shell；必须用时参数走数组形式，绝不拼接字符串；
  • [ ] 敏感数据：令牌不要明文写配置；考虑系统 keychain（keyring crate）；
  • [ ] 更新信任链：私钥只在 CI secrets；发布产物不可变，不覆盖已发布包；
  • [ ] 依赖卫生：定期更新、关注安全公告；前端同样做审计。

一条总原则：所有跨边界输入（前端参数、文件内容、URL、环境变量）都是不可信的， 在边界处校验，内部才能保持简单。

10.3 性能清单 ​

  • [ ] 命令默认异步；CPU/IO 重活使用 spawn_blocking，不阻塞主线程；
  • [ ] 长任务用事件上报进度，而不是让用户盯着转圈；
  • [ ] 前端输入防抖、大列表虚拟化、重依赖懒加载；
  • [ ] release profile 启用 LTO / strip（第 7 章）；
  • [ ] 用数据说话：先测量（devtools Performance、日志时间戳）再优化，拒绝玄学；
  • [ ] 控制序列化边界的体积：列表接口不要返回大字段全量。

10.4 工程化清单 ​

  • [ ] 语义化版本：三平台版本号一致，tag 与版本一致；
  • [ ] CI 三平台矩阵每次合并都跑（编译 + 前端检查）；
  • [ ] 发布走 tag 触发的固定流程，不在本地手工打包（可复现 > 方便）；
  • [ ] 密钥/证书集中管理，成员变动时可轮换；
  • [ ] 变更记录（Release Notes）面向用户写，不贴 commit 流水账；
  • [ ] 重大变更分小步提交——本教程每章一个版本，随时可回滚到任意学习节点。

10.5 进阶功能地图 ​

按「与本教程的距离」排序，学完即可上手：

方向要点提示
多窗口Window/label、窗口间事件通信复用第 3 章事件知识
系统托盘tray icon、菜单、最小化到托盘TrayIconBuilder
全局快捷键注册/注销组合键global-shortcut 插件
深度链接注册 URL scheme，从浏览器唤起应用deep-link 插件
剪贴板读写剪贴板clipboard-manager 插件
本地数据库SQLite（连接池、迁移）tauri-plugin-sql 或 rusqlite
自绘标题栏decorations: false + 自绘按钮 + 拖拽区域先确认产品真的需要
移动端Tauri Mobile：iOS/Android 目标复用大部分 Rust，前端需适配触控与小屏
嵌入式 Web/Bay 扩展WebAssembly、调用本地 AI 模型资源走 bundle.resources

每个方向都沿用同一套心智模型：官方插件 → 注册 → capability 授权 → 前端封装 → 错误/日志补齐。

10.6 推荐学习资源 ​

  • Tauri 官方文档（v2）：配置 schema 与插件权限的最终权威；
  • Tauri GitHub Examples：每个插件的最小可运行示例；
  • Rust 官方学习资料：所有权、生命周期、异步运行时——Rust 基础决定 Tauri 天花板；
  • 各平台开发者文档：WebView2 / WKWebView / WebKitGTK 的行为差异以官方为准。
