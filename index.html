这个系列怎么学 ​

一条主线：每一章都在完善同一个桌面笔记应用 AniNotes（动漫笔记）——而不是看完一堆互不相干的 demo。

两份产物：

  1. docs/ —— 你正在看的动漫式图文教程，包含图解、步骤、坑点提示与课后练习；
  2. app/ —— 可直接运行的 Tauri 项目，随章节演进，用 Git 标签式的提交节奏管理。

建议节奏：每章先通读 → 对照 app/ 自己敲一遍 → 完成章末练习 → 再进入下一章。
